# Afterburner visual study

`afterburner-reference.png` is AI-generated concept art used as a visual target. It is not a gameplay screenshot.

`public/assets/effects/afterburner-plasma.png` is a separate AI-generated transparent texture. The game wraps it around the aircraft's 3D exhaust mesh, with a recessed nozzle glow and WebGPU heat distortion. Both PNGs are stored with Git LFS.
